## 👤 About Me

I am an Infrastructure & Systems Engineer based in Minas Gerais, Brazil, with hands-on experience in production environments, network perimeter defense, virtualization, and systems administration.

- 🌐 **Enterprise Infrastructure:** Daily operations with Huawei switches (S5735-L / S310 stacks), Fortinet Fortigate firewalls (NAT, IPsec/SSL VPNs, policies), Windows Server (Active Directory, DNS, DHCP, GPO), Linux servers, and Microsoft 365 / SharePoint administration.
- ⚙️ **Virtualization & Resiliency:** Virtual machine cluster management via Proxmox VE & VMware ESXi, backed by Veeam Backup & Replication.
- 🚀 **NetDevOps & Automation:** Automating device provisioning and state audits with Python (`netmiko`), Terraform, Docker, and shell scripting.
- 🤖 **Multi-Agent Systems & AI:** Designing deterministic harnesses, Model Context Protocol (MCP) servers, and agent workflows across Anthropic Claude, Google Gemini, and OpenAI ecosystems.
- 🛡️ **Zero-Trust Engineering:** Strict adherence to secretless repos (Bitwarden Secrets Manager / BWS) and automated pre-commit secret scanning (Gitleaks).
